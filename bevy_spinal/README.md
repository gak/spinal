# Historical Bevy prototype

This directory retains the original Bevy 0.8 adapter for repository history
and archaeology. It is excluded from the active workspace and is not part of
the supported build.

The production Bevy 0.18 plugin will be implemented fresh around Bevy asset
loading, render extraction, and the standalone `spinal` core. This prototype's
sprite-sheet and per-region entity design is not the new architecture.
