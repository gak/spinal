# Historical Spine example exports

These files were added to Spinal's original 2022 history for development and
regression work. They are historical Spine 4.1 exports, not normative fixtures
for the 4.3.23 target and not part of any packaged crate.

The original commits did not record the exact downloaded archive. The project
names, filenames, and data identify them as exports of Esoteric Software's
official Spineboy and Raptor example projects. On 2026-07-30, the exact official
4.1 example download URLs were checked and both archives contained the
`LICENSE-ESOTERIC.txt` notice reproduced in each directory. The current
archives are not byte-for-byte provenance for these older captured exports.

The example images may be redistributed only with that notice and may not be
used commercially. Spinal's `MIT OR Apache-2.0` license does not apply to these
assets.
