# 2022 prototype archive

This directory retains the original project-owned Spinal implementation that
was present at revision `f7cb9f424f1c8a30ab56e3c22c368bb2f20f2b0d`.

The files are preserved for clean-room provenance and archaeology. They are
not compiled, packaged, or treated as compatibility evidence for Spine 4.3.
Their former dependencies and incomplete behavior are intentionally not
maintained here.

The active implementation lives in `spinal/src/`. New work may reuse ideas
from this archive because it was authored by the project under the same
clean-room restriction, but every current format claim still needs a source
registered in `SOURCES.toml`.
