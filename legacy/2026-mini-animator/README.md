# Archived mini animator prototype

This directory preserves an experimental, project-shaped procedural animation
prototype. It writes runtime JSON and assumes a particular four-legged IK rig,
so it is intentionally excluded from the active workspace, packages, and
Spinal Application Consolidation.

The active product keeps `.spine` projects canonical and does not include a
procedural animation editor. Reuse only generic runtime tests or ideas after an
independent design review; do not restore this prototype to `bevy_spinal` or
the Spinal application as-is.
